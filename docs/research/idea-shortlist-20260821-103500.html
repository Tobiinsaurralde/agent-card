Winner · rank 1

solana-execution-mcp v2 — firma que no se drena

Un agente puede pedir firmar. Turnkey evalúa. Las dos txs que hoy atraviesan el cap de 0.1 SOL (SystemProgram.createAccount y dos transfers de 0.09 en la misma tx) salen denied. Las 4 tools de lectura se quedan. No hay broadcast en el MVP.

Por qué gana. Es el único lugar donde tu repo ya es la evidencia, el nombre del paquete deja de mentir, y no estás peleando el catálogo de Helius. El workaround feo del mercado es literal: SOLANA_PRIVATE_KEY en el mcp.json de Solinkify, Nory, Nonagon, AgentBazaar, pr402.

Por qué crypto es necesario. Sin Solana no hay instruction layout que evaluar. IAM de AWS no entiende PDAs. Stripe no firma SPL.

Bear: si la gente acepta pegar una key drainable, esto es un blog post. Sobrevive porque el demo ya corre contra Turnkey y el install es un npx.

Integra, no buildees protocolo: Turnkey Policy Engine + simulación RPC. Cero programa Anchor nuevo.
